## 2. 확인된 핵심 메커니즘

### 2.1 제한시간 배치 → 일괄 전투

- 모래시계 바가 **5.7초**에서 실시간으로 감소 (프레임 1 → 13에서 5.6초 → 3.2초, 실시간 일치)
- 이 시간 동안 영웅을 드래그해 배치
- 프레임 17에서 타이머 바 소멸 → 프레임 20부터 데미지 숫자 출력
- 즉 **배치 페이즈 종료 후 전투가 자동 일괄 실행**

### 2.2 이동 규칙 — "한 명만 직접, 나머지는 자리바꿈"

프레임 3, 9, 13에서 **연두색 잔상 경로**(이동 궤적)가 관찰됨. 프레임 3에서는 두 영웅이 한 칸에 겹쳐 보임.

- 플레이어는 **영웅 한 명만 직접 드래그** 가능
- 그 영웅이 아군 위를 지나가면 **서로 자리가 스왑**됨 (십자 + 대각선 모두 가능)
- 이 스왑을 연쇄시켜 팀 전체를 재배치 → **이 게임의 핵심 퍼즐**
- 몬스터나 지형에 막히면 스왑 불가

### 2.3 공격 유형 3종

| 유형 | 판정 |
|---|---|
| **근접 (Melee)** | 인접 1칸. 클래스에 따라 십자(cardinal) 또는 8방향 |
| **원거리 (Ranged)** | 공격 패턴 내 **첫 번째** 적만 타격 |
| **마법 (Magic)** | 패턴 내 **모든** 적을 관통 타격 (힐러 포함) |

프레임 15~17에서 엘프 2명이 파란 해골 2기를 **좌우 협공 위치**로 진입 →
프레임 20~25에서 **2933 / 2941 / 2930 / 1267 / 3727** 데미지가 동시다발 출력.
광역 공격이 여러 적에게 중첩 적용된 결과.

### 2.4 공격 순서

- 영웅은 **마지막으로 움직인 순서**대로 공격 (직전 라운드의 이동 이력 포함)
- 직접 드래그한 영웅이 **항상 먼저** 공격
- 움직이지 않은 영웅은 팀 편성 순서대로
- 몬스터는 **move-count가 높은 유닛부터**, 동률이면 매 턴 랜덤

> **함의**: 드래그 순서 자체가 전략 변수. Finishing Blow, Princess 버프 등은 순서에 따라 발동 여부가 갈림.

## 3. UI 해독 (원본 해상도 확대 결과)

### 3.1 영웅 카드

| 위치 | 의미 |
|---|---|
| 좌상단 초록 잎 | 속성 (Green) |
| 우상단 도끼/검 아이콘 | **공격 패턴 표시** (도끼 = 8방향 근접) |
| 좌하단 `95` | 영웅 레벨 (영상 내 전원 95 = 만렙 팀) |
| 초록 막대 | 현재 HP |
| 하단 방패 뱃지 | 활성 버프 (주황 = 공격 / 파랑 = 방어 / 눈송이 = 빙결 계열) |
| 카드 테두리 색 | 등급 (분홍 / 금색 / 초록) |

### 3.2 적 유닛

- **아이스 킹**: 2×2 크기, 체력바가 **9칸으로 분할**
- 주변 해골 머리 위 **빨간 불꽃** = 화상 도트딜
- 앞줄 2기의 파란 **`4` 뱃지** = 방어막(배리어) 수치로 추정
- 좌우 가장자리 **흰 곰 4기**는 영상 전체에서 단 한 칸도 이동하지 않음

### 3.3 전투 이펙트

프레임 22 / 25 / 28에서 피격 지점에 **주황색 원형 이펙트** 반복 등장 → **패리(damage reduction) 발동 표시**로 추정.
패리는 통상 20%씩 **곱연산 누적**.

### 3.4 미확인 항목

> HP 바 우측 끝의 **청록색 뱃지 숫자** (엘프 `25`, 덤불 `12`)
> - 턴이 지나도 값이 불변 → 카운트다운 아님
> - 유닛마다 다름 → 고정 스탯 계열
> - 방어막 수치 또는 장비/각성 관련 값으로 추정
> - **게임 내에서 유닛 길게 눌러 영웅 인스펙터로 확인 필요**

## 4. 속성 상성

```
청(Blue) → 적(Red) → 녹(Green) → 청(Blue)
광(Light) ↔ 암(Dark)
```

유리한 상성일 때 **×1.5** 배수 적용.

---

## 5. 데미지 계산 공식

### 5.1 공격측

```
최종 데미지 = 기본 공격력
            × 리더스킬 배수
            × (1 + 탤런트 합)
            × 색상 상성 (유리 시 1.5)
            × 히어로 보너스 (1.00 ~ 1.25 랜덤)
```

- 탤런트는 보통 **+0.25**씩, 종족 특효는 **+0.5**
- 발동 조건을 만족한 탤런트만 계산에 포함 (예: Sniper는 대상이 2칸 이상 떨어져야 발동)

### 5.2 방어측

```
받는 피해 = 입력 데미지 × 0.8^A × 0.5^B × (종족 패리 0.8 ~ 1.0)
```

- `A` = 20% 감소 효과 개수 (패리, Nature's Harmony 등)
- `B` = 50% 감소 효과 개수 (몬스터 클래스 특성 등)

### 5.3 몬스터 클래스별 특성 (배치 판단에 직결)

| 클래스 | 특성 |
|---|---|
| Beast | 근접 데미지 **-50%** |
| Skeleton | 원거리 데미지 **-50%** |
| Clockwork | 마법 데미지 **-50%** |
| Dragon / Lizard | 대각선 데미지 **-50%** |
| Insect | 십자 데미지 **-50%** |
| Goblinoid | 풀피일 때 공격력 **+25%** |
| Ghost | 공격당 **1 데미지**만 받음 |
| Golem | **모든 디버프 면역** |
| Celestial | 턴 시작 시 Def의 100%만큼 회복 |

## 7. 배치 최적화를 위해 필요한 정보

### 7.1 필수 제출 항목

**① 턴 시작 시점 보드 스크린샷**
- 전체 보드가 나오도록 1장
- 지형(자갈 / 물 / 용암 / 벽)까지 함께 판독

**② 영웅 정보** — 카드 길게 눌러 인스펙터 캡처

- [ ] 이름 / 클래스 / 색 / 종족
- [ ] **Atk, Def, HP** 실수치
- [ ] **탤런트 전체 목록** ← 데미지 배수의 핵심
  - 특히 `Sniper`, `Backstab`, `Push`, `Tumble`, `Whirlwind`, `Finishing Blow` 유무
- [ ] **리더가 누구인지** (팀 맨 왼쪽) — 리더스킬 배수가 전체에 곱연산

**③ 몬스터 정보** — 동일하게 길게 눌러 확인

- [ ] **클래스** (Skeleton / Beast / Clockwork … 감쇄 방향이 완전히 다름)
- [ ] HP / Atk
- [ ] **AI 타입**
- [ ] 보스의 크기와 이동 가능 여부

### 7.2 산출물

정보가 모이면 컨테이너에서 솔버를 작성해 실행:

1. 스왑 체인으로 **도달 가능한 모든 배치** 열거
2. 각 배치에 클래스별 공격 패턴 적용 → 총 데미지 계산
3. 위 §5 공식으로 킬 여부 판정
4. 적 AI를 시뮬레이션해 **다음 턴 피격량** 산출
5. **딜 최대화 안** / **생존 최우선 안**을 분리 제시 + **드래그 순서**까지 지정

### 7.3 사전 인지할 한계

| 한계 | 내용 |
|---|---|
| **난수 존재** | 히어로 보너스 1.00~1.25, 종족 패리 0~20% → 결과는 단일 수치가 아닌 **구간 + 킬 확률**로 제시 |
| **실행 가능성** | 5.6초 안에 손으로 수행 가능해야 함. 스왑 12번짜리 이론적 최적해는 무의미 → **3~5스텝 현실안 우선** |
| **순서 의존성** | 공격 순서가 "마지막에 움직인 순서"라 드래그 순서가 결과를 바꿈 |
